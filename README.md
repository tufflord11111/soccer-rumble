# Soccer Rumble

Top-down chibi soccer for the browser: ranked 1v1 online with ELO (up to G.O.A.T.), practice vs bots, friends rooms with invite links, custom matches and training.

**Play:** https://tufflord11111.github.io/soccer-rumble/

- One self-contained `index.html` (vanilla canvas 2D, WebAudio, PeerJS inlined for peer-to-peer online play).
- This copy has no CrazyGames SDK tag; the portal build adds it.

## Test online (two devices)
1. Open the play link on two devices on different networks (e.g. laptop on Wi-Fi, phone on mobile data).
2. **Friends:** Friends → Create room on one; type the code (or open the invite link) on the other.
3. **Ranked:** tap Play Ranked on both within a few seconds.
